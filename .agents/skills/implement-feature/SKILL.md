# Implement Feature

When implementing a feature:

1. Read and follow the repository's AGENTS.md.
2. Read documentation relevant to the requested feature.
3. Search the existing codebase for similar implementations.
4. Reuse existing patterns, utilities, types, and abstractions.
5. Implement the smallest appropriate change.
6. Add or update tests.
7. Run relevant tests and checks.

Before finishing, report:
- files changed
- design decisions
- tests run
- assumptions or unresolved issues
